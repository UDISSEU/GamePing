# GamePing

Protótipo de um site que reúne promoções de jogos de várias lojas (Steam, Epic, GOG, Xbox e PlayStation), com comparador de preços, histórico e alertas personalizados. Feito com Figma Make, React e Vite.

## Requisitos

- Node.js 22
- pnpm 10 (via Corepack)

## Desenvolvimento

Na raiz do repositório, instale as dependências e inicie o servidor:

```bash
corepack pnpm install
corepack pnpm dev
```

## Build e pré-visualização

```bash
corepack pnpm build
corepack pnpm preview
```
